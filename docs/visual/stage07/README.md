# رندر سه ابزار — مرحلهٔ ۷

شش تصویر از رندر واقعی widget test در نمای ۹۰۰×۱۲۰۰ گرفته شده‌اند:

- `oee-form.png` و `oee-details.png`
- `npv-form.png` و `npv-details.png`
- `cp-form.png` و `cp-details.png`

هر جفت شامل فرم/نتیجه و سپس فرمول و توضیحات پس از اسکرول است. فونت Vazirmatn، Material Icons و face اصلی خانواده‌های ریاضی از bundle بارگذاری شده‌اند؛ build واقعی از همهٔ وزن‌ها و styleهای font manifest استفاده می‌کند. این تصاویر طراحی خیالی نیستند، اما اسکرین‌شات نصب روی Windows/Android، golden baseline یا تأیید DPI بومی هم نیستند. host تست صفحه را مستقیم باز می‌کند و Back مسیر واقعی ممکن است در آن دیده نشود.

بازتولید:

```sh
flutter test --dart-define=CAPTURE_PROTOTYPE_VISUALS=true test/features/calculators/prototypes/prototype_visual_test.dart
```

این سه تست در اجرای عادی عمداً skip می‌شوند تا فایل‌های تصویری ناخواسته تولید نکنند. اجرای جداگانهٔ این مرحله هر سه را با موفقیت گذرانده است.

موارد بررسی‌شده: نمایش **۸۳٫۷۹٪** و نسبت **۰٫۸۳۷۹**، رندر ضرب/جمع/کسر و سیگما، جهت فرمول LTR در صفحهٔ RTL، واحدهای نتیجه، توضیح زمان جریان‌های نقدی و فرض‌های آماری، متن مثال و تفسیر. برای جلوگیری از معکوس‌شدن معادلات در مثال فارسی، isolateهای LTR به متن مثال اضافه شدند.

آزمون چیدمان خودکار هر سه صفحه در تم تاریک و اندازه‌های ۳۲۰×۵۶۸ و ۱۲۸۰×۸۰۰ با text scale ۱٫۵ موفق بود. آزمون بومی کیبورد/IME، ماوس و Tab، صفحه‌خوان و DPI واقعی هنوز باقی است.
