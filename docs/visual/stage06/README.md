# رندرهای واقعی صفحهٔ عمومی ماشین‌حساب

چهار تصویر از widget test با فونت محلی Vazirmatn، Material Icons و fontهای بستهٔ رندر ریاضی گرفته شده‌اند:

- `light-desktop-form.png`: فرم و نتیجه، نمای ۹۰۰×۱۳۰۰ روشن.
- `light-desktop-details.png`: بخش فرمول، راهنما، مثال و تفسیر در همان نما پس از اسکرول.
- `dark-mobile-form.png`: فرم و نتیجه، نمای ۳۹۰×۸۴۴ تاریک.
- `dark-mobile-details.png`: بخش آموزشی پس از اسکرول در نمای کوچک.

این‌ها mockup یا تصویر تولیدشده با هوش مصنوعی نیستند؛ از صفحهٔ Flutter رندر شده‌اند. بااین‌حال، اسکرین‌شات نصب بومی Android/Windows، golden baseline یا گواهی عملکرد DPI واقعی نیستند. برای capture فقط face اصلی هر خانوادهٔ فونت بارگذاری شده است؛ build واقعی از تمام وزن‌ها/سبک‌های ثبت‌شده استفاده می‌کند. host تصویربرداری page را مستقیم باز می‌کند، پس ممکن است دکمهٔ Back مسیر واقعی را نداشته باشد.

بازتولید:

```sh
flutter test --dart-define=CAPTURE_CALCULATOR_VISUALS=true test/features/calculators/presentation/calculator_visual_test.dart
```

در اجرای عادی suite این دو تست برای جلوگیری از تولید فایل عمداً skip می‌شوند. آزمون محاسبات و widgetهای فرم مستقل از آن‌ها اجرا می‌شود.

موارد بازبینی‌شده: متن و labelهای RTL، محدوده‌های عددی/فرمول LTR، خوانایی دو تم، رندر ضرب و تقسیم فرمول LaTeX، برچسب واحد، مثال و تفسیر. فاصلهٔ suffix واحد در بازبینی اصلاح شد. تست خودکار چیدمان در ۳۲۰×۵۶۸ و ۱۲۸۰×۸۰۰ با text scale ۱٫۵ و هر دو تم نیز موفق بود.

باقی‌مانده برای بررسی واقعی: صفحه‌کلید و IME روی Android، Tab/ماوس در Windows، صفحه‌خوان و focus، DPIهای متفاوت، و تست روی دستگاه‌های دارای Android API 26 و Windows x64. رندر فرمول‌های پیچیده‌تر مرحلهٔ هفتم و بعد باید با دادهٔ واقعی همان ابزارها تست شود.
