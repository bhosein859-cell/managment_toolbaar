# بازبینی بصری مرحلهٔ ۴

`lab-light.png` و `lab-dark.png` از رندر واقعی widget test با فونت محلی و Material Icons، در نمای منطقی ۹۰۰×۱۰۰۰ گرفته شده‌اند؛ mockup یا تصویر تولیدشده با هوش مصنوعی نیستند. این تصاویر اسکرین‌شات نصب روی Android یا Windows و golden baseline خودکار نیستند. برای ثبت تصویر، فونت Regular بارگذاری می‌شود و وزن پررنگ می‌تواند توسط موتور رندر ساخته شود؛ در اجرای واقعی اپ فایل‌های Regular و Bold از pubspec استفاده می‌شوند.

بازتولید:

```sh
flutter test --dart-define=CAPTURE_VISUALS=true test/localization/visual_capture_test.dart
```

تست تصویربرداری در اجرای عادی suite عمداً skip می‌شود تا هر بار فایل خروجی ننویسد. خود تست‌های UI و عددی مستقل از آن اجرا می‌شوند.

بررسی این اجرا: اتصال حروف فارسی و نیم‌فاصله در متن نمونه، جدا ماندن فرمول انگلیسی و عدد/واحد، محل بازگشت در سمت راست، آیکون جهت‌دار و خوانایی دو تم بازبینی شدند. جهت فلش بازگشت به راست و فلش ورود/حرکت به چپ در RTL مطابق رفتار Material است.

## چک‌لیست دستگاه‌های واقعی — هنوز انجام نشده

- Android API 26 و یک نسخهٔ جدیدتر: صفحهٔ خوش‌آمدگویی، نام سازنده، خانه، تنظیمات و آزمایش فارسی.
- Windows x64، پنجرهٔ کوچک/بزرگ و DPIهای ۱۰۰٪، ۱۵۰٪ و ۲۰۰٪.
- هر سه حالت تم؛ تغییر ظاهر سیستم در حالت system، بدون تغییر انتخاب صریح light/dark.
- ارقام فارسی، عربی و لاتین؛ ممیز، منفی، copy/paste، اصلاح وسط متن و صفحه‌کلید واقعی.
- صفحه‌خوان، فوکوس با Tab و بزرگ‌کردن متن.
- تأیید وزن‌های Regular/Bold و fallback حروف انگلیسی روی هر پلتفرم.

تست خودکار بدون خطای layout در ۳۲۰×۵۶۸ و ۱۲۸۰×۷۲۰ با مقیاس متن ۱٫۵ اجرا شده است؛ این جای آزمون DPI یا صفحه‌کلید واقعی را نمی‌گیرد. در صفحهٔ کوچک امکان اسکرول برای رسیدن به دکمهٔ ورود وجود دارد.
