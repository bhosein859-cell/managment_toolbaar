# ویژگی‌ها

هر ویژگی سه لایه دارد:
- `domain`: مدل‌ها، قرارداد repository و منطق مستقل از Flutter.
- `data`: پیاده‌سازی ذخیره‌سازی و قراردادهای domain.
- `presentation`: صفحه‌ها و مدیریت وضعیت؛ وابسته به domain، نه جزئیات data.

ویژگی‌ها از جزئیات داخلی یکدیگر import نمی‌کنند؛ اتصال وابستگی‌ها در app انجام می‌شود.
پوشه‌های بدون کد فعلاً با `.gitkeep` نگهداری می‌شوند؛ قابلیت ساختگی ایجاد نشده است.
